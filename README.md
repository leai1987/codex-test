# AI Visual Creator

Адаптивное одностраничное портфолио на HTML, CSS и JavaScript, без внешних зависимостей. Все иллюстрации созданы средствами CSS и работают без загрузки внешних ресурсов.

Запуск: `npm start`, затем откройте http://localhost:3000.

Карточки открывают описания концептуальных проектов. Кнопка «Связаться» открывает контактное окно. Контактные данные владельца не предоставлены: замените текст внутри `#contact-dialog` в `index.html` на реальный email или ссылку на мессенджер перед публикацией.

Проверка JavaScript: `npm run check`.
