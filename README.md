# PURE MOTION — Ирина Лазаренко

Персональное портфолио AI-креатора: AI-видео, AI-фотография, сайты и контакты. Кинематографичный дизайн, мобильная навигация, доступные диалоговые окна проектов и поддержка уменьшенного движения.

## Запуск

`npm start` — http://localhost:3000. Установка зависимостей не нужна. Также можно открыть `index.html` напрямую.

`npm run check` — проверка синтаксиса JavaScript.

## Файлы

- `index.html`, `style.css`, `script.js` — основная страница.
- `assets/memory-cinema.png` — специально сгенерированный AI-триптих; изображения используются локально, без внешних сервисов.
- `portfolio-standalone.html` — автономная версия с встроенными стилями, скриптом и изображением.
- `preview.png` — полный мобильный скриншот страницы при ширине 390 px.

Карточки содержат описания визуальных концепций. Готовое видео не опубликовано, поэтому карточка фильма открывает описание концепции. Раздел сайтов ссылается на автономную версию действующего портфолио.

Имя и контактный email взяты из настроенного Git-профиля владельца репозитория. Для изменения контактов отредактируйте ссылки `mailto:` в `index.html` и пересоберите автономную версию.
